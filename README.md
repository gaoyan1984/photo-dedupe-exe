# 照片查重工具（图形界面 EXE 版）

> **↓ 快速下载**：[photo-dedupe.exe](https://github.com/gaoyan1984/photo-dedupe-exe/releases/download/v1.0/photo-dedupe.exe) —— 单文件，双击即用，无需安装 Python。


这是 [photo-dedupe](https://github.com/gaoyan1984/photo-dedupe) 的**打包成品**：一个 Windows 下双击即用的图形界面照片查重工具，**无需安装 Python**。

## 下载

到本仓库的 **Releases** 页面，下载 `photo-dedupe.exe`（即「照片查重」工具，单文件、约 31 MB），放到任意文件夹**双击即可运行**。如需中文名，可手动把它重命名为 `照片查重.exe`。

## 功能

- **扫描查重**：可同时选择**多个文件夹或磁盘**，按图片内容（MD5）比对，找出重复照片。
- **一键报告**：自动生成 A/B/C 三类 HTML 报告（含缩略图、可折叠分组、勾选容量统计），并打开浏览器查看。
- **预览清理**：先预览重复清单与可释放空间，**不删任何东西**。
- **三种处置**：移到回收站 / 备份到指定目录 / 直接永久删除（需二次确认）。
- **停止按钮**：扫描过程中可随时**停止**，立即终止、不碰任何文件。

## 使用方法

1. 双击 `photo-dedupe.exe`（下载后默认文件名）。
2. 在「① 扫描查重」里点 **添加文件夹** 或 **添加磁盘**（可多选），加入要扫的路径。
3. 点 **开始扫描**（只读，不动文件）。扫完会自动生成报告并打开浏览器。
4. 需要停止就点 **停止扫描**。
5. 后续清理（移回收站 / 备份 / 永久删）请先看预览、确认后再执行。

更详细的图文说明见 [使用说明.md](使用说明.md)。
